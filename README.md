# Todo-react-avancado
## Tecnologias utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

- **React** – Biblioteca JavaScript para construir interfaces de usuário.
- **JavaScript** – Linguagem de programação principal do projeto.
- **CSS** – Estilização das interfaces.
- **HTML** – Estrutura do frontend.
  - **React Hooks** para gerenciamento de estado e ciclo de vida dos componentes.
  - **LocalStorage** ou outro método de persistência de dados no navegador.
  - **React Context API / Redux** (opcional) para gerenciamento de estados mais complexos.
  - **Bibliotecas de UI** (opcional) como Styled Components, Tailwind CSS ou Material UI.

## Como rodar o projeto
1 -Clone o repositório:
```bash
git clone https://github.com/Pnb22/Todo-react-avancado.git

## 2 - Entre na pasta do projeto:
cd Todo-react-avancado
## 3 - Instale as dependências:
npm install 
## 4 - Rode o projeto:
npm start
## 5 - Acesse no navegador:
http://localhost:3000
